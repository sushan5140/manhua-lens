MANHUA LENS 0.3.0 - EDGE INSTALLATION

1. Extract this ZIP to a permanent folder.
2. Open edge://extensions in Microsoft Edge.
3. Turn on Developer mode.
4. Remove or disable the older Manhua Lens copy.
5. Click Load unpacked and select the manhua-lens folder (the folder that contains manifest.json).
6. Refresh any comic/webpage tabs that were already open.
7. Select text on a normal http:// or https:// webpage to test it.
8. If no panel appears, click the Manhua Lens toolbar icon once. It will check and activate itself on the current page.

Notes:
- Edge does not run extensions on edge:// pages or the Edge Add-ons store.
- Pronunciation uses Edge's extension-level text-to-speech support.
- If a language voice is missing, add it in Windows Settings > Time & language > Speech, then reload the extension.
- If online sentence translation is unavailable, bundled dictionary results will still be shown when possible.
- Version 0.3 includes offline dictionaries for 11 languages plus draggable, resizable, foldable panel controls.
