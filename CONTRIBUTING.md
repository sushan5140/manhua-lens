# Contributing to Manhua Lens

Thanks for helping improve Manhua Lens.

## Good first contributions

Useful contributions include:

- Reporting a reproducible bug
- Improving Korean, Japanese, Chinese, French, or Spanish dictionary data
- Fixing language-processing edge cases
- Improving accessibility or the reading-panel UI
- Clarifying documentation
- Suggesting focused features for language learners and comic readers

## Before opening a change

1. Check whether a similar issue already exists.
2. Keep changes focused on one problem when possible.
3. Describe what changed and how you tested it.
4. Avoid committing generated files, local settings, or unrelated formatting changes.

## Bug reports

A useful bug report should include:

- Browser and version
- Source and target language
- A short example of the selected text
- What you expected to happen
- What actually happened
- Steps that reproduce the issue

Please avoid sharing private or sensitive webpage content in public issues.

## Feature suggestions

Explain the reading or language-learning problem first, then describe the feature you think could solve it. Small, testable improvements are easier to evaluate and maintain.
